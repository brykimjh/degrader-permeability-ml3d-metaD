## Abstract
This poster describes work on improving permeability prediction for heterobifunctional degraders using machine-learning models augmented with metadynamics-informed three-dimensional descriptors. The approach integrates physics-based sampling with data-driven modeling to improve ranking and prioritization in early discovery workflows.
